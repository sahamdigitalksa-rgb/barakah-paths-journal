# Barakah Paths Journal

I want to build a website that will be on wordpress CMS. The website will be called Barakah Paths, which means Blessed path in Arabic. The purpose of this website is to document our family's journey making Hijrah from Singapore to Madinah, and it should be where we capture our learnings, reflections and moments for those who are in the same journey or embarking in the same journey. Secondary to that, it's for our own consumption and possible for extended families. 

Primary themes would be on life as a family, starting homeschooling, exploring and immersing in Arabic culture, learning the language, faith and so on. There should be a blog section, a section for videos,

Make sure that all elements are editable on Elementor. It has to be SEO friendly and code must not be heavy that will impact the site speed. 

This is an about us page that I already drafted to capture the feeling of the website. Propose the colour scheme, branding, logos or even placeholder photos for the build.
