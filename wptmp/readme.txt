=== Barakah Paths ===
Requires at least: 6.0
Tested up to: 6.6
Requires PHP: 7.4
License: GPLv2 or later

A light, fast, search-friendly journal theme for a family's Hijrah from Singapore to Madinah.

== Install ==
1. WordPress admin > Appearance > Themes > Add New > Upload Theme.
2. Choose barakah-paths-wordpress-theme.zip, click Install, then Activate.
   The categories Family life, Homeschooling, Arabic & culture, Faith and Videos are created automatically.

== Create your pages ==
Pages > Add New, then in the right panel pick "Template":
- Home (no template needed) - then Settings > Reading > "A static page", Homepage = Home.
- Journal (blank page) - set as "Posts page" in Settings > Reading.
- Videos - template "Videos".
- Themes - template "Themes".
- About - default template; paste your About text.
- Guides - template "Guides (shop landing)". Install WooCommerce to sell digital guides.

== Menus and logo ==
Appearance > Menus: create a menu and tick "Primary menu". Appearance > Customize > Site Identity to upload a logo (otherwise the built-in stacked logo is shown).

== Writing ==
Posts > Add New. Pick one theme category, add a featured image and a short excerpt (used for Google descriptions). For videos, choose the Videos category and paste a YouTube link into the post.

== SEO ==
Titles, Google descriptions, social previews and structured data are built in. If you install Yoast, Rank Math, AIOSEO, SEOPress or The SEO Framework, the theme's own tags turn off automatically. Settings > Permalinks: choose "Post name".

== Elementor ==
Any page can be edited with Elementor (free). Use the Elementor template pack delivered separately.

Photos included are illustrative placeholders; replace them with your own.
